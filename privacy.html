개인정보처리방침

시행일: 2026년 11월 3일

쓰로틀머니(Throttle Money)의 운영자 최장민은 개인정보 보호법 등 관련 법령에 따라 개인정보 처리 내용을 안내합니다. 회원가입 없이 기록을 기기에 저장하는 방식을 기본으로 하며, 외부 정보 조회·광고·분석·오류 진단 및 이용자가 선택한 제보·공유 과정에서는 아래 정보가 외부에서 처리될 수 있습니다.

1. 수집하는 개인정보 항목

이용하는 기능과 설정·권한에 따라 다음 정보를 처리합니다.
- 기기 내 기록: GPS 위치·경로·거리·시간, 수입·지출·정비 내역, 차량 정보, 메모·감정 일기, 위치 메모·개인 후면단속 지점, 검색어·즐겨찾기 및 앱 설정
- 배달 자동 기록: 선택한 배달 앱의 화면 글자·버튼 정보를 일시적으로 읽고 플랫폼·완료 금액·감지 시각·중복 방지 식별자와 처리 결과를 기기에 저장. 화면에는 고객 주소·이름·요청사항이 포함될 수 있으며 세부 범위는 제5항에 안내
- 앱 바로가기: 기기에서 조회하는 앱 이름·아이콘, 선택한 앱 식별자, 최근 앱 자동 표시를 선택하고 사용 정보 접근을 허용한 경우에 조회하는 최근 앱 사용 이력
- 외부 조회: 현재 위치 또는 선택한 위치의 좌표·날씨 격자·지도 조회 영역, 검색어·선택한 지점과 콘텐츠, 통신에 수반되는 IP 주소 및 요청 정보
- 분석·오류 진단·광고: 앱 설치·광고 등 식별자, 앱·운영체제·기기 정보, 화면·기능 이용 이벤트, 운행 시작·종료·모드·시간, 오류·충돌·성능 정보, 광고 표시·클릭·시청 등 상호작용과 IP 주소 기반 대략적 위치
- 제보·문의: 발신 이메일 주소, 선택한 제보자 이름·별명, 이름 공개 동의 여부, 제보 지점의 이름·좌표·주소·제한속도·방향·수정 시각, 메모·첨부 파일·앱 버전 및 이용자가 직접 보낸 문의 내용

2. 개인정보의 처리 목적

  • 운행·가계부·정비·통계·일기 및 개인 지점 관리, 위치 기반 알림 제공
  • 동의한 배달 앱의 완료 금액 자동 기록과 누락·중복 확인
  • 지도·날씨·주유소·CCTV 등 외부 정보 조회, 앱 바로가기 제공
  • 이용 현황 분석, 오류 진단·성능 개선, 원격 설정·공지 제공 및 앱·기기 무결성 확인
  • 광고 제공·성과 측정·부정 이용 방지 및 광고 시청 보상 처리
  • 제보·문의 검토·회신, 공용 지점 데이터의 검증·반영, 별도 동의한 이름의 크레딧 공개
  • 이용자가 요청한 백업·복원·내보내기·공유

3. 외부 서비스 이용 및 정보 전달

외부 처리가 없는 기기 내 기록과 다음 외부 통신을 구분합니다. 이용하는 기능에 따라 각 제공자에게 요청 정보가 전달됩니다.
- Google: Google Analytics for Firebase의 이용 분석, Firebase Crashlytics의 오류 진단, Firebase Remote Config의 설정·공지 조회, Firebase App Check 및 Play Integrity의 무결성 확인, Google Mobile Ads(AdMob)의 광고 제공에 식별자·이용·진단·통신 정보 등을 처리합니다. Analytics는 앱 시작 시 활성화되고 Crashlytics는 릴리스 앱에서 활성화됩니다. 광고는 광고 설정에 따라 SDK 초기화와 요청이 이루어집니다.
- 기상청·OpenWeather: 날씨 조회에 위치를 변환한 격자 좌표 또는 위도·경도를 전달합니다. 기상청 조회가 실패하면 OpenWeather로 대체 조회할 수 있습니다.
- Google·네이버·카카오 지도 및 기기의 주소 변환 제공자: 선택한 지도·주소 조회 기능에 필요한 좌표·조회 영역·검색 또는 요청 정보가 처리될 수 있습니다.
- 주유소·CCTV 조회 프록시와 해당 정보·영상 제공기관: 주변 주유소 조회 좌표, CCTV 조회 영역·검색어·선택한 영상 등 해당 요청 정보가 전달됩니다. 영상 직접 재생 또는 공식 페이지 연결 시 해당 제공자와도 통신합니다.
- GitHub Pages: 공용 후면단속 데이터·크레딧·공개 문서 조회 시 IP 주소 등 웹 요청 정보가 전달됩니다. 웹 문서의 외부 글꼴을 불러올 때에는 글꼴 제공자와도 통신합니다.
- 기기의 음성 안내 엔진: 운행·수입·알림 등의 음성 안내를 사용할 때 읽어줄 문구를 기기에 설정된 음성 합성 엔진으로 전달합니다. 엔진의 네트워크 이용 여부와 정보 처리는 해당 엔진의 설정·정책에 따릅니다.
- 메일·공유·파일 저장 서비스: 이용자가 제보·문의·백업·내보내기·공유를 실행하면 선택한 앱이나 저장 위치로 해당 정보가 전달됩니다. 개발자 제보는 이용자가 메일 앱에서 전송을 완료한 경우 운영자가 수신합니다.

서비스 제공에 따른 처리위탁과 외부 제공자의 독립적인 목적에 따른 처리는 해당 서비스의 계약·정책과 법령에 따라 구분합니다. 법령상 별도 동의가 필요한 제공·위탁·이전은 해당 요건을 충족해야 하며, 이 방침의 공개 자체가 별도 동의를 대신하지 않습니다. 법령이 정한 적법한 요구에 따라 정보를 제공할 수 있습니다.

4. 위치 정보의 처리

운행·경로 기록과 위치 기반 알림을 위해 위치 정보를 사용하며, 권한과 운행 상태에 따라 앱이 화면에 표시되지 않을 때에도 위치를 사용할 수 있습니다. 운행 경로와 개인 기록은 기기에 저장하는 것을 기본으로 합니다.

날씨 조회에는 날씨 격자 또는 위도·경도, 주변 주유소 조회에는 조회 좌표, CCTV 지도 조회에는 좌표 범위가 외부로 전달됩니다. 지도·주소 조회에도 필요한 위치 정보가 사용될 수 있습니다. 조회 기준은 현재 위치 또는 이용자가 선택한 위치일 수 있습니다. 운행 경로 전체를 이들 조회의 기본 요청 항목으로 전송하는 것은 아닙니다.

이용자는 위치 기능을 중지하거나 Android 설정에서 위치 권한을 해제할 수 있습니다. 권한을 거부하면 해당 위치 기반 기능이 제한됩니다. IP 주소로 추정하는 대략적 위치는 GPS 권한을 해제해도 광고·외부 통신 과정에서 처리될 수 있습니다.

5. 접근성 서비스의 처리

배달 수입 자동 기록 기능을 사용자가 선택하고 동의한 경우에만 Android AccessibilityService API를 사용합니다. 선택한 배달 앱 화면에서 접근성 서비스가 제공하는 글자와 버튼 정보를 일시적으로 읽습니다. 이 과정에서 화면에 표시된 고객 주소·이름·요청사항도 읽힐 수 있습니다. 배달 완료 금액을 장부에 자동 기록합니다. 배달 앱의 버튼을 대신 누르거나 화면을 캡처하지 않습니다.

플랫폼·배달 완료 금액·감지 시각·중복 방지 식별자를 사용자의 기기에 저장하며 자동으로 외부 전송하지 않습니다. 수락 시각과 포인트는 자동 수집하지 않습니다. 사용자가 문제 기록을 켜면 완료 금액 감지·자동 기록 처리 결과와 필요한 화면 구조 정보를 최대 500건·24시간 기기에 보관합니다. 고객 주소·이름·요청사항·사진·상점명·주문번호 원문과 화면 원문은 저장하거나 자동 전송하지 않습니다. 사용자가 진단 파일 보내기를 직접 선택한 경우에만 진단 정보가 공유 기능을 통해 전달될 수 있습니다.

사용자는 앱 설정에서 자동 기록과 접근성 서비스 사용을 언제든지 중지할 수 있습니다. 접근성 서비스를 중지하면 이 기능은 더 이상 배달 앱 화면을 확인하지 않습니다.

6. 이용자의 권리

기기 내 기록은 해당 기능에서 제공하는 수정·삭제 또는 앱의 "데이터 초기화"로 관리할 수 있습니다. 초기화는 앱이 관리하는 기록·설정 등을 삭제하는 기능이며 외부 저장소의 백업, 이미 보낸 메일·공유본, 공개된 데이터의 사본이나 외부 SDK 서버의 정보를 함께 삭제하지는 않습니다. 앱을 삭제하면 해당 기기에서 앱의 새로운 정보 처리는 중단되지만 이미 외부에서 처리된 정보가 즉시 모두 삭제되는 것은 아닙니다.

제보·문의 정보의 열람·정정·삭제·처리정지 및 이름 공개 동의 철회는 제14항의 이메일로 요청할 수 있습니다. 필요한 범위에서 요청자와 대상 정보를 확인한 뒤 법령에 따라 처리합니다. 대리인을 통한 행사에는 대리 권한 확인이 필요할 수 있습니다. 법령에 따라 요청이 제한되는 경우 그 사유를 안내합니다. 본인 확인을 위해 불필요한 주민등록번호·신분증 원본 등을 보내지 마세요.

접근성·위치·사용 정보 접근 등은 앱 또는 Android 설정에서 중지·해제할 수 있습니다. 광고 ID는 Android의 광고 관련 설정에서 삭제·재설정할 수 있으나 다른 식별자나 이용·진단 정보까지 모두 중지되는 것은 아닙니다. 현재 앱에는 Analytics·Crashlytics 수집을 개별적으로 끄는 설정이 없습니다. 이들 서비스에 이미 전달된 정보에 관한 요청은 문의처로 접수할 수 있으며, 특정 이용자 정보의 식별 가능 범위와 제공자의 절차에 따라 처리합니다.

7. 앱 내 로컬 저장 정보

본 앱은 CCTV 기능 제공을 위해 최근 검색어 및 즐겨찾기 정보를 사용자의 기기 내에만 저장할 수 있습니다.
저장된 최근 검색어 목록과 즐겨찾기 목록 자체를 자동 전송하지는 않습니다. 다만 검색을 실행하거나 영상을 선택하면 해당 조회에 필요한 검색어·영상 정보는 외부 제공자에게 전달될 수 있습니다. 앱 삭제 또는 데이터 초기화를 통해 앱 내부 목록을 제거할 수 있습니다.

앱 바로가기는 사용자가 선택한 앱 식별자를 기기에 저장하며, 사용자가 만든 백업에 해당 설정이 포함될 수 있습니다. 최근 앱 자동 표시용 사용 이력은 앱 바로가기가 켜져 있고 다른 앱 위에 표시될 때 기기에서 조회하고 일시적으로 메모리에서만 사용합니다. 이력을 파일이나 백업에 저장하거나 서버로 전송하지 않으며, 앱 바로가기 또는 최근 앱 자동 표시를 끄거나 Android의 사용 정보 접근을 해제하면 조회를 중지합니다.

8. 제보·문의와 공개 크레딧

제보·문의 전송 시 운영자는 이메일 주소·본문·첨부 파일을 수신할 수 있습니다. 제보 지점은 검토 후 공용 데이터에 반영되어 앱과 공개 데이터 파일로 배포될 수 있습니다. 연락처·개인 사정이나 타인의 개인정보를 지점 이름·주소 설명·메모 등에 불필요하게 포함하지 마세요.

제보자 이름은 선택 사항이며 이름을 비워도 제보할 수 있습니다. '감사한 분들'의 이름 공개는 별도 선택 동의가 있을 때에만 앱과 공개 크레딧 파일에 반영하며, 동의하지 않아도 제보 검토에 불이익이 없습니다. 공개 동의를 철회하거나 공개 내용의 정정·삭제를 요청하려면 제14항의 이메일로 연락해주세요. 운영자가 관리하는 공개 자료를 수정한 뒤에도 기기의 오프라인 캐시나 이미 배포·저장된 사본에는 이전 정보가 남을 수 있으며, 모든 사본의 일괄 회수를 보장하지 않습니다.

9. 백업·내보내기·공유

이용자가 실행한 백업에는 운행·장부 등 앱 DB와 설정이 포함될 수 있으며, CSV·이미지·개인 지점·진단 파일 공유에는 선택한 기능의 정보가 포함됩니다. 이용자가 고른 메일·클라우드·메신저·파일 저장 앱의 처리에는 해당 제공자의 정책이 적용됩니다. 공유 전에 포함 정보와 수신자를 확인하고 외부에 저장한 사본은 해당 저장 위치에서 직접 관리·삭제해야 합니다. 앱 내부 데이터 초기화나 삭제만으로 외부 사본이 삭제되지는 않습니다.

10. 보유기간 및 파기

  • 기기 내 기록·설정: 이용자가 삭제·초기화하거나 앱을 삭제할 때까지 보관하는 것을 기본으로 합니다. 최근 앱 자동 표시용 사용 이력은 일시적으로 메모리에서만 처리합니다. 외부에 만든 백업·공유본은 이용자가 해당 저장 위치에서 삭제할 때까지 남을 수 있습니다.
  • 배달 자동 기록의 문제 기록: 최대 500건·24시간 범위로 관리하며 이용자가 진단 화면에서 삭제할 수 있습니다.
